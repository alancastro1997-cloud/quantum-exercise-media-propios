# Quantum Fitness & Health — medios propios de ejercicios

GIFs e imágenes de ejercicios grabados y editados por el Dr. Alan Castro para los planes
de entrenamiento de Quantum Fitness & Health. Uso interno del pipeline clínico Quantum.

- `gifs/` — animaciones para el plan HTML.
- `imagenes/` — fotograma estático para el Doc de Google (Google Docs no anima GIFs).
- `lista-ejercicios-propios.md` — catálogo de nombre de ejercicio → archivo.

Todo el contenido es propiedad de Quantum Fitness & Health, sin relación con el dataset
de terceros (`exercises-dataset`, © Gym Visual) que usa el resto del pipeline.
